SpeechAnalyzer Live Mic
===========================

A Swift package and SwiftUI example for learning how to connect an iOS microphone
to Apple's SpeechAnalyzer. The package has no third-party runtime dependencies.
Its source and these documents are available under the MIT license.

Start with :doc:`getting-started` for app permissions and package setup. Use
:doc:`api` to understand the public types, and :doc:`troubleshooting` when audio
arrives but transcription does not.

Project context
-------------------

The sample is maintained by the SimpleMemo developer, 株式会社ユリカ. It explores
on-device voice capture used in note-taking workflows. The related application's
`voice input page <https://simplememofast.com/voice-input/>`_ explains that
product context. This package itself does not send emails or store notes, and
using it requires no SimpleMemo account or subscription.
